# Reglas de Asociación y Sistemas de Recomendación · Streamlit

Dashboard interactivo de la guía de clase (Danilo Gómez Correa): ejemplo de 7 canastas, exploración de
*Groceries* (9.835 tickets, 169 productos), minería con Apriori / FP-Growth, test de Fisher + Holm,
reglas redundantes, grafos interactivos, cadena de compras, recomendador y evaluación HitRate@N.

Local: `pip install -r requirements.txt && streamlit run app.py`
